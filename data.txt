# data paths
- raw
	- CPIS
		- 'World_CPIS_2000.shp' # from https://github.com/DetectCPIS/
		- 'World_CPIS_2021.shp' # from https://github.com/DetectCPIS/global_cpis_shp; see readme for details
	- Africa_shp
		- Africa_Boundaries.shp # from https://hub.arcgis.com/datasets/07610d73964e4d39ab62c4245d548625/explore

- intermediate
	- CPIS
		- combined_CPIS.shp # all CPs in Africa sensed in 2000 or 2021, with pivots sensed in both years combined. Has an ID column. Created in code/1_CP_shapefile/1_filter_combine_CPs.py
		- SSA_CPIS.shp # combined_CPIS.shp but only in sub-Saharan Africa. Has an ID column. Created in code/1_CP_shapefile/2_filter_to_SSA.py
	- SSA_shp
		- SSA_Boundaries.shp # Boundaries of only countries in sub-Saharan Africa. Created in code/1_CP_shapefile/2_filter_to_SSA.py
	- 2_data_request	
		- 'stratified_cp_ids.txt'
			- Contains a list of stratified ID pivots in Africa, giving a representative subset of pivot ID's used for model training. Created in code/2_data_request/1_stratified_filter_cp.py
		- training_data_C02
			- Series of roughly 1000 TIF images gathered from Google Earth Engine which will be used to label for model training. Contains images from landsat collections: 5, 7, 8, and 9.
			  TIF images have undergone preprocessing of scaling and qa masking prior to being exported. Gathered from code/2_data_request/2_download_training_data.py
	- 3_labeling
		- jpeg_training_images
			- Series of RGB, NDVI, and LST images created from our TIF training data used for labeling annotations. Created in code/3_labeling/image_creator.py
	- 4_data_pipeline
		- 'band_names_training.txt'
			- Contains the band names of each TIF image gathered from Google Earth Engine, allowing insight to the band structure and organization of the training data. Created in code/4_data_pipeline/1_band_names.py
